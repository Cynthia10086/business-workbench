01 / CLI
从项目目录调用
支持初始化、知识检索、案例更新与导出。每次调用返回 JSON，适合具备终端能力的 Agent。
python3 workbench/cli.py \
  --workspace ../business-data \
  knowledge_search \
  --payload '{"query":"销售下降"}'
02 / MCP
作为本地工具服务
在支持 MCP stdio 的 Agent 中添加启动命令。启动参数使用产品和工作目录的实际路径。
python3 workbench/mcp_server.py \
  --workspace ../business-data
