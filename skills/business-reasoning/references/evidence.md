# 证据与持续归因

## 不同内容承担不同作用

| 内容 | 可支持的判断 | 不能代替什么 |
| --- | --- | --- |
| 用户当前陈述 | 用户报告的现象、背景或目标 | 独立核验 |
| 当前案例原始材料 | 该材料实际记载的事实 | 材料未覆盖的时间、人群和结果 |
| 同源抽取、摘要 | 便于定位和检索原件 | 新的一份独立证据 |
| 方法知识 | 解释机制、拆解问题、设计验证 | 当前业务已经成立的原因 |
| 历史案例 | 类比、候选机制、条件对照 | 当前案例的事实 |
| Agent 旧回答 | 分析过程、当时假设和计划 | 用户事实或外部观察 |

保留材料的来源家族、时间、对象范围、页码或定位。不同文件名不代表不同来源；不同来源家族也不自动代表统计独立。

## 引用与推导

事实引用使用 `{kind: "message" | "source", id, quote}`。`quote` 必须是当前案例真实用户消息或已经解析材料中的逐字片段。将原始观察与推导分开：计算写明公式、输入引用和口径；没有输入的推算写为假设。方法记录、Agent 消息和未解析原件不能作为事实引用。

知识来源可以使用记录 ID、原文档名、页码和段落定位。若知识记录保留了图形解释的不确定项，本轮不得悄悄删掉这些限制。

## 竞争解释与强度

为每个解释维护支持与反证，说明还缺什么能区分解释的信息。没有证据的候选解释可以保留为空支持，不为填满表格编造证据。

- 未评估：只有可理解的解释。
- 相关：变化相伴出现，但尚未排除替代解释。
- 机制得到支持：看到与该机制一致的中间过程，仍可能存在混杂。
- 因果证据：研究或验证设计足以支持相应范围内的因果判断，仍需说明设计与边界。

这些级别描述论证状态，不是通用统计量。优先检查一个解释，可能因为它影响大、可逆或信息容易获得，不表示它最可能为真。

## 新信息与反证

更新状态时保留旧对象 ID、原主张文字和已有引用。需要更正文字或增加范围限定时，新建一个 ID 承载修订后的主张，将旧项标为 `superseded` 并记录更正理由；不要直接改写旧项的 `text`。新证据削弱原结论时，标记被削弱、被反驳或待重新检查，并记录变化理由；不通过删除旧反证让结论变得更强。旧证据后来被发现错误时，保留引用及更正原因。版本冲突时读取最新状态再合并，不能覆盖另一次分析。

## 图形和跨行业迁移

对图形逐项辨认节点、方向、边类型、层级、坐标、包含或重叠关系。区分原图内容与 Agent 派生解释。示意面积和线宽只有在图注明示时才可当作数量信息。

跨行业应用时分别检查客单、购买频次、决策周期、服务责任、库存形态、供应约束和渠道角色。可以迁移提问方式与分析结构；阈值、指标公式、动作节奏和有效机制须由目标业务资料验证。
